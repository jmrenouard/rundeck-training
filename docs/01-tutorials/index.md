# Tutorials

Learning-oriented hands-on exercises for deploying Rundeck with Docker, configuring ACL policies, and running Ansible or MinIO/S3 jobs.

1. [Docker Rundeck Quickstart Lab](01-docker-rundeck-quickstart.md) — validate `docker/docker-compose.yml`, initialize `docker/.env`, start Rundeck and MySQL, and import `docker/jobs/sample-job.yml`.
2. [Ansible, ACLPolicy, and MinIO S3 Integration Lab](02-ansible-acl-and-minio-lab.md) — build a multi-document `.aclpolicy`, generate `realm.properties`, inspect Ansible playbooks, and configure `templates/rundeck/minio/transfert-s3.yml`.
